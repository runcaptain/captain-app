# Captain changelog

What's New shows these notes. The upstream CHANGELOG.md stays in the tree for merges and is never shown.

## [0.1.13] - 2026-11-06

### New
- **Captain.** Investigations, Data and signals, Runs, Comparisons and Handoff, as native screens, with terminals
  and agents beside them.
- **Tasks in plain words.** New, the palette and the tour open designed forms: start an investigation, import a
  dataset, connect a database or a cloud account, add a place to run work, run a backtest, start grading, hand off
  a candidate.
- **Spaces per workspace.** Each space is bound to a workspace, and its terminals know it and any investigation.
- **Light, Dark and System**, from the sidebar.
- **Which cloud you're on**, in the sidebar, with Cloud and compute behind it.
- **Everything Captain needs comes inside the app.** Nothing to install separately.
